# 개인정보 처리방침
POS AI SaaS

최종 업데이트: 2026-03-11

POS AI SaaS(이하 "회사")는 이용자의 개인정보를 중요하게 생각하며 관련 법령을 준수합니다. 본 개인정보 처리방침은 회사가 어떤 정보를 수집하고 어떻게 사용하며 보호하는지를 설명합니다.

---

## 1. 수집하는 개인정보

회사는 서비스 제공을 위해 다음 정보를 수집할 수 있습니다.

### 회원가입 및 서비스 이용

- 이메일
- 이름
- 전화번호
- 사업자 정보
- 접속 로그
- IP 주소
- 쿠키

### SNS 연동 (Facebook 등)

사용자가 SNS 계정을 연결하는 경우 다음 정보를 수집할 수 있습니다.

- Facebook 페이지 ID
- Facebook 페이지 이름
- 게시 권한 토큰
- 게시물 관리 권한

이 정보는 SNS 자동 게시 기능 제공을 위해서만 사용됩니다.

---

## 2. 개인정보 이용 목적

회사는 수집한 개인정보를 다음 목적에 사용합니다.

1. 사용자 계정 관리
2. POS 매출 분석 서비스 제공
3. SNS 자동 마케팅 기능 제공
4. 고객 문의 대응
5. 서비스 개선 및 통계 분석
6. 법적 의무 준수

---

## 3. 개인정보 보관 기간

| 정보 유형 | 보관 기간 |
|-----------|-----------|
회원 정보 | 회원 탈퇴 시까지 |
서비스 로그 | 최대 3개월 |
법적 보관 정보 | 관련 법령에 따름 |

---

## 4. 개인정보 제3자 제공

회사는 이용자의 개인정보를 외부에 제공하지 않습니다.

다만 다음 경우는 예외입니다.

- 이용자가 동의한 경우
- 법적 요구가 있는 경우
- 서비스 제공을 위해 필요한 경우

예시 서비스

- Meta (Facebook API)
- Google Cloud
- Supabase

---

## 5. 개인정보 처리 위탁

서비스 제공을 위해 다음 업체를 사용할 수 있습니다.

| 업체 | 역할 |
|------|------|
Supabase | 데이터 저장 |
Google Cloud | 서버 및 AI 분석 |
Meta | SNS 게시 기능 |

---

## 6. 개인정보 보호 조치

회사는 개인정보 보호를 위해 다음을 시행합니다.

- HTTPS 암호화
- 접근 권한 관리
- 데이터 암호화
- 서버 보안 관리
