# [서비스 기획서] POS 인사이트 AI (POS Insight AI)
**버전:** 2.0 (Next.js 기반 풀스택 아키텍처 고도화)
**작성일:** 2026년 3월 12일
**대상:** 소상공인 및 매장 운영자

---

## 1. 프로젝트 개요

### 1.1 서비스 배경
많은 소상공인이 POS 데이터를 보유하고 있음에도 불구하고, 이를 분석하여 실제 경영에 활용하는 데 어려움을 겪고 있습니다. 본 서비스는 AI 기술을 활용하여 복잡한 데이터를 직관적인 인사이트로 변환하고, 재고 관리 및 마케팅 업무를 자동화하여 매장 운영의 효율성을 극대화하는 B2B SaaS(Software as a Service) 솔루션을 목표로 합니다.

### 1.2 서비스 목표
* **데이터 기반 경영:** 실시간 매출 분석 및 AI 예측을 통한 전략적 의사결정 지원.
* **운영 효율화:** 간편한 재고 관리 및 자동 발주 알림 시스템 제공.
* **마케팅 자동화:** AI를 활용한 SNS 홍보 콘텐츠 생성 및 원클릭 게시.
* **지능형 상담:** 매장의 실제 POS 데이터를 바탕으로 경영 고민을 해결해주는 AI 비서.

## 2. 주요 기능 상세

### 2.1 대시보드 (Dashboard)
매장의 전반적인 상태를 한눈에 파악할 수 있는 중앙 관제 화면입니다.
* **실시간 지표:** 금일 매출액, 주문 건수, 평균 객단가(ATV)를 시각화 (Next.js 서버 컴포넌트를 활용한 초기 렌더링 최적화).
* **매출 분석 차트 (Recharts 활용):**
  * 시간대별 매출 분포 (Bar Chart)
  * 요일별 및 월별 매출 현황 (Area Chart)
* **상품 랭킹:** 판매 금액 및 수량 기준 TOP 10 상품 리스트 제공.
* **AI 비즈니스 인사이트:** Gemini 모델이 주간/월간 데이터를 분석하여 현재 매장의 강점과 약점을 3줄 요약 제공.
* **외부 요인 분석 및 주간 예보:** 향후 7일간의 날씨 API 데이터를 연동하여, 날씨에 따른 예상 매출액과 추천 대비책(예: 비 오는 날 파전/막걸리 재고 확보) 제시.

### 2.2 재고 및 발주 관리 (Inventory)
매장 운영에 필수적인 식자재 및 소모품의 실시간 재고를 관리합니다.
* **재고 현황판:** 품목명, 현재 수량, 단위, 상태(정상/경고/부족) 표시.
* **실시간 수량 업데이트:** +, - 버튼을 통한 간편한 수량 조절 및 DB 실시간 동기화.
* **AI 수요 예측 기반 알림:** 특정 상품의 판매 추이를 분석하여 재고 소진 시점을 예측하고, 안전 재고 이하로 떨어지기 전 대시보드 알림 제공.

### 2.3 AI 마케팅 (Marketing)
매장 홍보를 위한 콘텐츠 생성 및 SNS 연동 기능을 제공합니다.
* **옴니채널 텍스트 생성:** '신메뉴 출시', '할인 이벤트' 등 목적을 입력하면, Gemini가 페이스북, 인스타그램 각각의 플랫폼 성격에 맞는 최적의 홍보 문구 초안 자동 작성.
* **미디어 업로드:** 홍보용 사진/동영상 업로드 (드래그 앤 드롭 지원).
* **원클릭 게시:** 소셜 플랫폼 API 연동을 통해 대시보드 내에서 즉시 게시물 업로드 (Next.js API Route를 통한 안전한 통신).

### 2.4 AI 경영 비서 (Chat)
매장의 데이터를 가장 잘 이해하는 1:1 맞춤형 채팅 서비스입니다.
* **데이터 기반(RAG) 컨설팅:** Gemini 3 Pro 모델이 사용자의 질문을 받으면, 백엔드에서 해당 매장의 최근 매출/재고 데이터를 컨텍스트로 함께 주입하여 매우 구체적인 답변 제공.
  * *질문 예시:* "이번 주말 비가 온다는데, 어떤 메뉴를 미리 준비하는 게 좋을까?", "최근 2주간 제일 안 팔린 메뉴의 식자재 소진 방법은?"
* **실시간 스트리밍:** Next.js Edge Runtime을 활용한 빠르고 자연스러운 대화형 UI 응답.

## 3. 시스템 아키텍처 및 기술 스택

기존 프론트엔드 중심 구조에서 보안과 개발 속도를 모두 잡을 수 있는 **Next.js 풀스택 아키텍처**로 개편합니다.

### 3.1 코어 기술 스택
* **Framework (Frontend & Backend):** `Next.js (App Router)`
  * SEO 최적화 및 서버 사이드 렌더링(SSR) 지원.
  * API Routes를 활용하여 별도의 Express 서버 없이 백엔드 로직 통합 구축.
* **Database & Auth:** `Supabase (PostgreSQL)`
  * B2B 서비스에 필수적인 강력한 사용자 로그인/인증 기능 지원.
  * POS 데이터 및 재고 정보의 빠르고 안정적인 실시간 데이터베이스 관리.
* **AI Engine:** `Google Gemini API`
  * 빠른 요약 및 응답: Gemini Flash
  * 복잡한 매출 분석 및 경영 컨설팅: Gemini Pro
* **UI & Styling:** `Tailwind CSS`, `Framer Motion` (애니메이션), `Lucide React` (아이콘).
* **Data Visualization:** `Recharts`.

### 3.2 보안 및 API 통신 구조
* **API Key 은닉:** Gemini API Key, Facebook API Key, Supabase Secret Key 등 민감한 정보는 클라이언트(브라우저)에 절대 노출하지 않고, Next.js의 서버 사이드 환경(`/app/api/...`)에서만 안전하게 호출하여 통신합니다.

## 4. UI/UX 디자인 가이드
* **메인 컬러:** `#F97316` (Orange 500) - 활기차고 긍정적인 에너지 전달.
* **보조 컬러:** `Slate 800/900` (신뢰감, 텍스트), `Emerald 500` (매출 상승, 긍정 지표), `Rose 500` (재고 부족, 경고).
* **타이포그래피:**
  * 제목: Black/Bold weight의 가독성 높은 Sans-serif 계열 (Inter 또는 Pretendard).
  * 본문: Medium weight.
* **컴포넌트 스타일:**
  * `rounded-[2rem]` 이상의 넉넉한 라운드 값을 사용하여 현대적이고 부드러운 SaaS 느낌 강조.
  * `border-orange-100`의 미세한 테두리와 `shadow-sm`을 활용한 컨텐츠 분리 및 깊이감 표현.

## 5. 향후 로드맵 (Phases)
* **Phase 1 (MVP):** 가상 데이터를 활용한 대시보드 구현 및 Gemini AI 연동 (현재 기획).
* **Phase 2 (Data Integration):** 실제 매장 POS 시스템(예: 배달의민족, 요기요, 오프라인 POS) API 연동을 통한 실시간 데이터 파이프라인 구축.
* **Phase 3 (Omnichannel Marketing):** 카카오톡 챗봇 알림, 인스타그램 연동 등 홍보 및 알림 채널 확장.
* **Phase 4 (Global):** 다국어 UI 지원 및 글로벌 POS 서비스와의 연동 확장.
